## 字体与预览

PPT 和 Word 的可编辑文本字体均指定为 **Microsoft YaHei**。字体本体未嵌入文件；原有图片、截图及机构标识内的字属于图像内容。

本机未检测到微软雅黑字体文件。为避免 LibreOffice 随机替换为书法字体，PDF 预览通过专用临时配置将 Microsoft YaHei 映射到本机中文无衬线字体（Hiragino / PingFang）。PPT 本身的字体设置保持为微软雅黑。在安装微软雅黑的 PowerPoint 中打开会按该字体排版。

## 研究结果来源与口径

1. **HoneyBee / MatSci-Instruct（2023，arXiv v1）**
   - [论文](https://arxiv.org/abs/2310.08511v1)，表 2（PDF 第 7 页）。
   - HoneyBee-7b without verification：Accuracy 85.42；HB-7b-Stage3：91.95。
   - 为 GPT-4 对其 MatSci-Instruct 测试数据的评价，变化同时涉及验证与迭代训练，不能当作单变量消融或独立实验真实性证明。
2. **LLaMat（2025-01-28，arXiv v2）**
   - [论文](https://arxiv.org/abs/2412.09560v2)，表 E.1（PDF 第 28 页）。
   - All MatNLP / Mean Micro-F1：LLaMA-3 chat FT 为 86.2250，LLaMat-3 chat 为 93.0270；PPT 四舍五入显示 86.23 → 93.03。
   - 涉及持续预训练与指令微调，评价任务是材料 NLP，不等同于任意开放问答质量。
3. **MELT（EMNLP Findings 2024）**
   - [论文与官方页面](https://aclanthology.org/2024.findings-emnlp.627/)，表 1（PDF 第 6 页）。
   - MatSci-NLP Overall Micro-F1：SciBERT 0.693，MELT 0.741。
   - 属于持续预训练，使用语义图与课程策略，不应归类为 QA 指令微调。
4. **背景概念**
   - [RAG，Lewis et al., 2020](https://arxiv.org/abs/2005.11401)。
   - [灾难性遗忘，Luo et al., 2023](https://arxiv.org/abs/2308.08747)。

三项工作为代表性研究，非截至某日的穷尽调查；不同论文分数不可横向排名。本项目目前汇报数据构建能力，未声称获得同样训练收益。

## 平台与真实数据来源

- [Materials Project 官方 API 示例](https://docs.materialsproject.org/downloading-data/using-the-api/examples)及[查询与来源字段说明](https://docs.materialsproject.org/downloading-data/using-the-api/querying-data)。现有项目 `07_docs/05_MATERIALS_PROJECT.md` 已记录 MP 风格的身份、筛选与 summary/API 参考。
- PPT 中的 **mp-7029 / SiO2** 来自 matminer `dielectric_constant` 公开快照：空间群 96、计算胞 12 原子、PBE 带隙 5.51 eV、总介电常数平均值 4.04。
  - 原始研究：[Petousis et al., Scientific Data 4, 160134 (2017)](https://doi.org/10.1038/sdata.2016.134)。
  - [公开数据文件](https://ndownloader.figshare.com/files/13213475)，来源类型为 MP 计算数据，PPT 明确标注为 2017 年快照，而非实时 API 或实验数据。
  - 文件 SHA-256：`8eb24812148732786cd7c657eccfc6b5ee66533429c2cfbcc4f0059c0295e8b6`，已与 matminer 元数据核对。
  - 对应行的 structure、CIF、性质与引用保存在 `source/mp7029_snapshot.json`。
- SteelDig 真实样品：`10.1002_srin.202400475` / `sample_fe-12mn-9al-3cr-1.4c-0.02nb__as-cast`。屈服 880±19 MPa，抗拉 1016±12 MPa，延伸率 39±2%。来自本地 `.data.json`，其溯源文件和原文块同目录保留。
- [Databricks Medallion](https://docs.databricks.com/aws/en/lakehouse/medallion)：原始、验证、服务的分层设计经验。
- [Pinecone 元数据过滤](https://docs.pinecone.io/guides/search/filter-by-metadata)：检索记录与元数据关联的经验。
- 后两项是本次新增的设计对照；本库实际为本地文件系统＋PostgreSQL / pgvector，没有声称部署过这两个平台，也没有把 Databricks 三层与本项目四层作一一等同。

## 图谱与数据库实现澄清

- 完整子图保存在 `source/actual_subgraph.json`，完整 QA 保存在 `source/qa_case.json`。
- 实际图中的 `interface_S0` 是界面/相演化记录，不能直接改称独立“富 Al 氧化膜”节点。膜形成受限的解释位于 r5 的边文本中。
- 生成器真正收到的是题型、出题焦点与事实卡；路径关系与证据继续写入审计记录。
- 四层是逻辑分工，事实与检索共用 PostgreSQL。
- 文件逻辑路径经 `lake.object_ref` 定位 `object_id`，再经 `lake.object.uri` 定位湖文件。
- `search.document` 保留 `doc_id / paper_id / sample_id / ref_id`。这些来源字段的关联不全部是数据库外键，部分由 ETL 和应用维持。
- 事实字段与 trace 的真实路径是 `$.properties[0].mechanical.tensile_properties.yield_strength[0]`，为项目当前使用的 JSONPath 风格，不是 RFC 6901 JSON Pointer。
- 保留原始规模数字，未重新执行入库或 SFT 生成，也未把不同历史运行的数量相加。
